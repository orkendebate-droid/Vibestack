# Трек 12: Казахтелеком (Спецтрек — Сравнение организационных структур и регламентов)

> **Бизнес-кейс:** Интеллектуальный аудит масштабной реорганизации крупнейшего телеком-оператора Казахстана (АО «Казахтелеком»).  
> **Входные данные:** Пакеты документов «ДО» и «ПОСЛЕ» реорганизации (положения о подразделениях, штатные расписания, должностные инструкции в форматах DOCX, PDF, Excel).  
> **Цель:** Разработать систему автоматического аудита оргструктур:
> - Сопоставить департаменты и службы: созданные, сохраненные, упраздненные и переименованные.
> - Выявить **потерю функций** (критически важная обязанность исчезла из регламентов).
> - Выявить **дублирование функций** (два разных отдела делают одно и то же).
> - Выявить **конфликты интересов** (например, подразделение само ставит задачи и само себя контролирует).
> - Подтвердить каждую находку **дословной цитатой** из документа с указанием номера пункта и страницы.

## 1. 🥇 Singularity (1 место)

### Стек технологий
- **Среда выполнения:** **Bun** (ультрабыстрый запуск и установка пакетов)
- **Frontend & App:** **Next.js 16**, **React 19**, TypeScript, Tailwind CSS 4, **shadcn/ui**, TanStack Table
- **Графы и схемы:** **React Flow** (интерактивное дерево оргструктуры)
- **Парсинг документов:** `mammoth` (Word), `unpdf`, `mupdf`
- **Локальный ML:** **ONNX Runtime Node** (быстрое извлечение эмбеддингов локально на процессоре)
- **ИИ-модель:** `gpt-6-sol`

### Киллер-фичи решения:
1. **Принцип «Детерминизм везде, где можно; LLM только для смысла»:** Код сам строит дерево отделов и сравнивает названия. Нейросеть привлекается только для поиска скрытых семантических дублей (когда функции описаны разными словами).
2. **Детекция битых ссылок (Broken Cross-References):** При реорганизации пункты регламентов часто перенумеровывают, и внутренние ссылки начинают ссылаться в никуда. OrgDiff автоматически находил все сломанные кросс-ссылки.
3. **Закоммиченный LLM-кэш для жюри:** Все ответы модели на тестовых документах зафиксированы в репозитории. Судьи запускали проект без ввода ключа OpenAI и получали моментальный отклик интерфейса.
4. **Экспорт в юридический DOCX:** Формирование официального экспертного заключения с таблицей разногласий.

## 2. 🥈 Optimus — OrgScope (2 место)

### Стек технологий
- **Backend:** Node.js 22 (Express 5, Zod) + Python 3.12 (FastAPI, pdfplumber, python-docx)
- **Frontend:** **Vue 3**, Vite, Caddy
- **Деплой:** Развернут на виртуалке в **Azure Cloud** с публичным демо-доступом

### Главные фишки:
- **Автоматическая сверка с законами РК:** Решение не просто сравнивало два документа, а сопоставляло функции безопасности и аудита с нормативными актами Республики Казахстан, давая кликабельные ссылки на портал `adilet.zan.kz`.
- **Защита от мусорных файлов:** Загрузка неподходящего документа (например, бухгалтерского чека) мгновенно останавливала конвейер с понятной ошибкой `irrelevant_document`.

### Главная фишка: Side-by-Side Diff с Human-in-the-Loop

- Эксперт по кадрам может поставить пометку: *«Принять изменение»*, *«Отклонить (дубликат)»* или *«Отправить на согласование юристу»*.

## 💡 Выводы для VibeStack:
1. **React Flow идеален для визуализации иерархий:** Дерево подчиненности на интерактивных блоках React Flow выглядит на порядок эффектнее статических таблиц.
2. **Цитаты должны быть верифицируемы:** Каждое утверждение ИИ должно сопровождаться подсвеченным фрагментом исходного документа.
3. **Пакетный менеджер Bun экономит время на хакатоне:** Установка зависимостей за 4 секунды вместо 2 минут на `npm`.
