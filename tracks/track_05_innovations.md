# Трек 5: Инновации (Кейс «Хаттама» — Автоматизация протоколов совещаний)

> **Бизнес-кейс:** Создание автономного ИИ-секретаря для госорганов и корпораций, способного обрабатывать многочасовые аудиозаписи совещаний на казахском, русском и смешанном языках.  
> **Цель:** Преобразовать сырую аудиозапись в официальный структурированный протокол:
> - Распознавание речи с высокой точностью (низкий WER) на казахском и русском языках.
> - Диаризация (разделение аудиопотока по конкретным спикерам).
> - Извлечение поручений: **что сделать**, **кто ответственный**, **в какой срок**.
> - Привязка каждого поручения к исходной цитате/таймкоду речи и экспорт в юридически корректный формат DOCX.

## 1. 🥇 KaskyrAlmaty (1 место)

### Стек технологий
- **Инфраструктура:** Self-hosted сервер на GPU (NVIDIA RTX 6000 Ada), **vLLM**, Docker Compose, пакетный менеджер **uv**
- **Распознавание речи (ASR):** Гибридный конвейер: **Whisper Large-v3** + **SeamlessM4T-v2** (специально для казахских фрагментов речи)
- **ИИ-агент:** **PydanticAI** + **Qwen 2.5 72B** (через локальный инференс vLLM)
- **Конфигурация агентов:** `CLAUDE.md` + `AGENTS.md`

### Киллер-фичи решения:
1. **Гибридный двуязычный ASR:** На чистом Whisper качество распознавания казахской речи давало Word Error Rate (WER) около 45%. Команда внедрила детектор языка и переключала аудиофрагменты с казахской речью на SeamlessM4T-v2, снизив ошибку **до рекордных 11% WER**.
2. **Верификация через PydanticAI:** Если LLM извлекала поручение и назначала исполнителя, которого не было в списке участников совещания, или ссылалась на несуществующий таймкод, валидатор PydanticAI отклонял генерацию и принуждал модель скорректировать вывод.
3. **Строгий Air-Gapped контур:** Система блокировала любые исходящие сетевые запросы за пределы защищенного сертифицированного периметра.

## 2. 🥈 BBC (2 место — Специальный приз NVIDIA Sovereign AI)

### Стек технологий
- **Инференс:** **Apple MLX** (для Mac) + кастомный адаптер **mlx_torch** (для Windows/Linux CUDA), ONNX Runtime
- **Модели:** **Whisper-turbo**, **PyAnnote** (диаризация спикеров), **Qwen 2.5 7B** (квантованная)
- **Backend & Frontend:** FastAPI, SQLite, React, Vite, TypeScript

### Киллер-фичи решения:
1. **100% оффлайн без облаков:** Решение работает без интернета на ноутбуке любого чиновника.
2. **Хакинг лимитов GitHub без Git LFS:** Чтобы не зависеть от платного Git LFS, команда скриптом разбила веса моделей на блоки по 48 МБ прямо в репозитории с проверкой контрольных сумм SHA-256 при первой сборке (`make`).
3. **Кроссплатформенность:** Одинаково быстро работает и на Apple Silicon через MLX, и на Windows с видеокартами NVIDIA RTX.

## 3. 🥉 Alabala – ToU (3 место — Специальный приз NVIDIA Accelerated AI)

### Стек технологий
- **Среда:** Windows 11 + WSL2, CUDA 12, **llama.cpp**
- **Модели:** **NVIDIA NeMo** (голосовая диаризация), **Gemma 12B**
- **Сервер:** Python, Waitress, FFmpeg

### Архитектура:
- **Разделение ресурсов железа:** Тяжелая языковая модель Gemma 12B была сжата и запущена на многопоточном CPU через `llama.cpp`, оставив всю видеопамять GPU под акустические модели NeMo и транскрибацию.
- **Инсталлятор `install.cmd`:** Запуск всего сложного ML-стека на «голой» Windows в одну команду.
